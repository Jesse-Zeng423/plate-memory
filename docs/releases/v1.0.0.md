# Plate Memory v1.0.0

A usable local terminal release: that bro who ate with you every day back in high
school. No account, API key or Python package installation needed for food browsing.
Python 3.10+ is required. Runtime app inference remains local.

## Start

Download `plate-memory-1.0.0.zip`, unzip, and run `python3 plate-memory.py` inside its
folder. macOS can use `start.command`; macOS/Linux can use `sh start.sh`. English
is the default; Simplified Chinese is available. `--demo` is a separate optional
synthetic mode. `--version` identifies the release.

## Included

- 3,535 attributed offline food references, keyword/loose-craving discovery,
  family browsing, related ideas and source/menu-check details.
- Two routes: takeout or campus cafeteria. Optional saved local places and dated
  prices; actual menu review with locally downloaded Gemma and deterministic guard.
- Friend-authored text lunchbox, optional actual-meal journal, editable local notes.
- Crayon friendship postcards: real HTML/text/importable JSON/share-folder export;
  optional PNG with an installed local Chrome/Chromium. Sharing is manual.
- English/Chinese interface, numbered navigation, retained session drafts and
  grapheme-aware narrow-terminal decoration.

## Data and boundaries

Confirmed personal records live in `private/` beside the app. No real records are
included in the download. Export folders contain only explicit card fields; optional
use link goes to public instructions. Files are owner-only on POSIX, not encrypted.
Move or back up your private folder yourself when replacing the app. Do not commit
or send that folder. Unsaved drafts disappear when you close the app.

Current prices, restaurant stock, recipe ingredients and nutrients are unknown.
These are ideas to check on your actual menu, not health rankings or dietary
clearance. Gemma setup is optional for browsing and required for AI menu extraction.
Harold's real use trial is still pending; no feedback has been invented. This
release is not a DEV submission and does not establish clinical or production
validation. The illustration depicts fictional friends.

## Verification

Required unittest, pytest, guard provenance and four mock scenarios pass. A fresh
release archive is extracted and launched from an unrelated directory, in normal
mode, with synthetic input and app sockets forbidden; its card export and version
are checked. Runtime fixtures are not evidence of Harold usability.
