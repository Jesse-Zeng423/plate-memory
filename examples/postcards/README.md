# Synthetic postcard examples

Every name, note and dish in this directory is explicitly synthetic. None is
Harold's real message, preference, meal, health information or trial reaction.
The table HTML/text/JSON/manifest are a real exported share bundle. The PNGs were
rendered by an isolated local Chrome instance and visually inspected at desktop
and 390-pixel card widths. The Chinese HTML uses the invitation theme. The public
link is a repository quick-start, not a hosted web app. Actual sharing is manual.

Current preview: short friendship note and a built-in image_gen crayon drawing.
Characters are fictional; prompt/provenance in assets/postcards/. HTML embeds the
local PNG as a data URL and does not fetch assets from the network.
